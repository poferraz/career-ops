# Support

For setup and host-specific installation steps, see the [quick start](README.md#try-it) and [Installation and integrations](docs/integrations.md).

## Before opening an issue

- **Verify your install path:** Run the smoke test in the [quick start](README.md#try-it) and confirm your host files match [docs/integrations.md](docs/integrations.md).
- **Test in a fresh session:** Start a new conversation to rule out stale instructions or earlier context overriding Career Ops.
- **Redact all personal data:** Remove real resumes, names, contact details, and confidential employer details from prompts, outputs, and screenshots — use fictional examples instead.

## Where to get help

- **Bugs, broken host exports, or feature proposals:** Choose the matching template on [GitHub Issues](https://github.com/poferraz/career-ops/issues/new/choose). Include your AI host, expected behavior, and actual output using fictional details.
- **Security or privacy issues:** Do not open a public issue. Use the private reporting channel in [SECURITY.md](SECURITY.md).
