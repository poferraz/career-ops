# Support

For setup, see the [quick start](README.md#try-it) and [host installation guide](docs/integrations.md).

For a bug or feature request, use the issue templates. Describe the host, what you expected and what happened. Use a fictional example in place of real application materials, names or contact details. [GitHub issues](https://github.com/poferraz/career-ops/issues/new/choose)

For a security or privacy issue, use the private reporting channel. [Security policy](SECURITY.md)
