# Clief Routing

This project runs the Clief/ICM operating system. Canonical context lives in `docs/clief/`.

Read `docs/clief/INDEX.md` first on every new task. It routes you to the right workspace context.

Rules:
- One fact, one location: `docs/clief/` is the only source of project facts.
- Load only the context the current task needs.
- Update `docs/clief/STATUS.md` at meaningful milestones.
