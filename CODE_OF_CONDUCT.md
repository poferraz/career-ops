# Code of Conduct

## Our Pledge

Career Ops is committed to providing a welcoming, inclusive, and respectful
environment for everyone, regardless of background, identity, or experience level.

## Our Standards

We expect all contributors and participants to:

- Use welcoming and inclusive language
- Respect differing viewpoints and experiences
- Accept constructive feedback gracefully
- Focus on what is best for the community
- Show empathy toward other community members

## Enforcement

This project adopts the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its Code of Conduct.

- **Public GitHub threads:** Use GitHub's built-in reporting controls on the relevant issue, pull request, or comment.
- **Off-thread or private conduct concerns:** Report privately so no reporter's personal information appears in public issues. You can contact the maintainer via a private [GitHub Security Advisory](https://github.com/poferraz/career-ops/security/advisories/new) (see [SECURITY.md](SECURITY.md)) or reach out directly through the maintainer's [GitHub profile](https://github.com/poferraz).
- **Security and privacy incidents:** Follow the private reporting process in [SECURITY.md](SECURITY.md).

## Scope

This Code of Conduct applies within all project spaces (GitHub Issues, pull requests,
and Discussions) and in public spaces when an individual is representing the project.
