# Evidence tiers

Career Ops uses these labels to describe the evidence behind a claim. A label in an existing guide records the project's classification. Check the original source and date before quoting a statistic or using it to advise an applicant.

| Tier | Evidence | How to use it |
| --- | --- | --- |
| T1 — verified | Relevant peer-reviewed research, public primary data or independently corroborated findings | Identify the study or dataset and the population and outcome it describes. |
| T2 — reported | An identified survey, platform analysis or individual industry experiment | Attribute the result to its source and include relevant limits of the sample or method. |
| T3 — conventional | Practitioner judgment, a writing technique or a coaching framework | Offer it as a technique the user can try. |
| T4 — excluded | A claim of unknown origin or one contradicted by stronger evidence | Omit it from advice. If the question matters, explain what evidence is missing. |

When sources disagree, compare their methods, dates and relevance to the user's market. Web research can surface new leads. An independent check of the underlying evidence is still required. [Research methodology](research-methodology.md) · [Research guide](../references/research-scout.md)
